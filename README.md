# TAMATAMA

**TAMATAMA** は、球体型ビデオプレイヤー **Crystal701** で「視る」ための動画を公開していくリポジトリです。

小さな球体の中で映えるアニメーションやループ動画などを、少しずつ掲載していく予定です。

## 公開する動画について

- 自作の動画を中心に掲載します。
- 第三者の著作権・商標権などを侵害するおそれがないと判断できるものだけを公開します。
- 既存のキャラクター、音楽、映像など、権利関係が不明な素材を含む作品は掲載しません。

## 対象ディスプレイ

**Crystal701** は、MP4動画とJPG画像に対応した球体型ビデオプレイヤーです。表示解像度は **480 × 480** ピクセル。掲載する動画は、必要に応じてディスプレイに適した形式・サイズに変換してお楽しみください。
