# TAMATAMA

**TAMATAMA** は、球体型ビデオプレイヤー **Crystal701** で「視る」ための自分用の動画を公開していくリポジトリです。

## 公開する動画について
- 自作の動画を中心に掲載します。
- 第三者の著作権・商標権などを侵害するおそれがないと判断できるものだけを公開します。
- videoフォルダに保存するとみることができます。

## 対象ディスプレイ
**Crystal701** は、MP4動画とJPG画像に対応した球体型ビデオプレイヤーです。
